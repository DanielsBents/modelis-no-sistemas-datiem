# modelis-no-sistemas-datiem

Projekts "Modelis no sistēmas datiem" prognozē rūpnieciskas iekārtas atteici, izmantojot AI4I 2020 Predictive Maintenance Dataset.

## Izmantotās bibliotēkas

- pandas
- scikit-learn

Instalēšana:

```bash
pip install pandas scikit-learn

```markdown

## Faili

- dati/ai4i2020.csv - sākotnējā datu kopa

- tirisana.py - datu tīrīšana

- modelis.py - modeļa apmācība un testēšana

- tirs.csv - attīrītie dati

- rezultati.md - rezultātu apraksts

## Palaišana

```bash
python tirisana.py

python modelis.py
```
